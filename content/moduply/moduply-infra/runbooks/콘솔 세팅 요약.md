# 콘솔 세팅 요약

## 지금 완료한 범위

비용이 거의 발생하지 않는 준비 작업만 진행했다.

```text
ECS Cluster
Task Definition
Security Group
```

## ECS Cluster

```text
Cluster name: moduply-cluster
Infrastructure: Fargate 기본 provider로 생성
EC2 Capacity Provider: 나중에 추가
```

Fargate provider는 나중에 삭제하지 않아도 된다. ECS Service 생성 시 사용할 capacity provider를 명확히 지정하면 된다.

```text
app-service → moduply-app-cp
redis-service → moduply-redis-cp
kafka-service → moduply-kafka-cp
```

## Task Definition 생성 원칙

```text
OS: Linux
Architecture: X86_64
Launch type: EC2
Network mode: awsvpc
```

리소스나 환경변수는 나중에 새 revision으로 변경할 수 있다.

## Redis 콘솔 입력

```text
Entry point: 비움
Command: redis-server,--appendonly,yes
Working directory: 비움
Volume: 지금은 설정하지 않음
```

## Kafka 콘솔 입력

```text
Image: confluentinc/cp-kafka:7.5.3
Entry point: 비움
Command: 비움
Working directory: 비움
Volume: 지금은 설정하지 않음
```

환경변수:

```text
KAFKA_BROKER_ID=1
KAFKA_NODE_ID=1
KAFKA_PROCESS_ROLES=broker,controller
KAFKA_CONTROLLER_QUORUM_VOTERS=1@localhost:9093
KAFKA_LISTENERS=PLAINTEXT://:9092,CONTROLLER://:9093
KAFKA_ADVERTISED_LISTENERS=PLAINTEXT://<Kafka EC2 private IP>:9092
KAFKA_LISTENER_SECURITY_PROTOCOL_MAP=PLAINTEXT:PLAINTEXT,CONTROLLER:PLAINTEXT
KAFKA_INTER_BROKER_LISTENER_NAME=PLAINTEXT
KAFKA_CONTROLLER_LISTENER_NAMES=CONTROLLER
KAFKA_OFFSETS_TOPIC_REPLICATION_FACTOR=1
KAFKA_TRANSACTION_STATE_LOG_REPLICATION_FACTOR=1
KAFKA_TRANSACTION_STATE_LOG_MIN_ISR=1
KAFKA_GROUP_INITIAL_REBALANCE_DELAY_MS=0
KAFKA_LOG_DIRS=/tmp/kraft-combined-logs
CLUSTER_ID=MkU3OEVBNTcwNTJENDM2Qk
KAFKA_HEAP_OPTS=-Xms1g -Xmx1g
```

`KAFKA_PROCESS_ROLES=broker,controller`는 단일 Kafka 컨테이너가 broker와 controller 역할을 같이 수행한다는 의미다. 띄어쓰기 없이 입력한다.

2026-07-23 실제 배포에서는 `docker.io/bitnami/kafka:3.7`가 manifest not found로 pull 실패했다. 로컬 compose와 맞춘 `confluentinc/cp-kafka:7.5.3`로 변경해 Kafka broker 기동과 App Kafka 발행을 확인했다.
