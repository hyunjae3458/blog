## 운영 모드

```text
부하테스트 모드
- 1만명 트래픽 테스트를 위해 Spring App, Redis, Kafka, RDS를 분리
- ALB + ACM 기반으로 트래픽을 받음
- 병목을 관측할 수 있는 구조

상시 운영 모드
- 취업 준비 기간 동안 포트폴리오 링크를 계속 유지
- 같은 구조를 유지하되 인스턴스 수와 스펙을 축소
- 월 비용을 줄이는 구조
```

## 현재 예비 세팅 상태

2026-07-15 기준 콘솔에서 비용이 거의 발생하지 않는 범위의 예비 세팅을 진행했고, 2026-07-16에 상시 운영용 분산환경으로 실제 재배포했다.

```text
완료:
- ECS Cluster 생성
- Spring App Task Definition 생성
- Redis Task Definition 생성
- Kafka Task Definition 생성
- OS/Architecture는 Linux / X86_64 기준
- ALB + ACM + Route 53 HTTPS 연결
- RDS PostgreSQL 생성
- App ASG / Redis ASG 생성
- ECS EC2 Capacity Provider 연결
- Spring App service / Redis service 배포
- App은 bridge 모드, Redis는 awsvpc 모드로 운영

남은 작업:
- Kafka ASG / Capacity Provider / Service 구성
- Redis 내부 DNS 구성
- SSE 연결 종료 처리 개선
```
