# 예비 세팅 기록

## 생성 완료

2026-07-15 기준 콘솔에서 다음 예비 세팅을 완료했다.

```text
ECS Cluster
- 이름: moduply-cluster
- 최초 생성 시 Fargate 기본 capacity provider 사용
- EC2/ASG는 아직 연결하지 않음

Task Definition
- moduply-app-task
- moduply-redis-task
- moduply-kafka-task

공통 Runtime Platform
- OS: Linux
- CPU architecture: X86_64
```

## 아직 생성하지 않은 것

비용 발생을 피하기 위해 아직 생성하지 않는다.

```text
ALB
RDS
EC2 ASG
ECS Capacity Provider
ECS Service
ElastiCache
MSK
NAT Gateway
Elastic IP
```

## 추후 연결할 Capacity Provider

하나의 ECS Cluster에 역할별 Capacity Provider를 붙인다.

```text
moduply-cluster
├─ moduply-app-cp
│  └─ moduply-app-asg
├─ moduply-redis-cp
│  └─ moduply-redis-asg
└─ moduply-kafka-cp
   └─ moduply-kafka-asg
```

Fargate provider는 남아 있어도 된다. 실제 ECS Service 생성 시 EC2 capacity provider를 명확히 선택하면 Fargate로 실행되지 않는다.

## ASG 계획

부하테스트용:

```text
moduply-app-asg: 2 / 2 / 3
moduply-redis-asg: 1 / 1 / 1
moduply-kafka-asg: 1 / 1 / 1
```

상시 운영용:

```text
moduply-app-asg: 1 / 1 / 1
moduply-redis-asg: 1 / 1 / 1
moduply-kafka-asg: 0 / 0~1 / 1
```

표기 순서:

```text
min / desired / max
```
